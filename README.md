# Can AI Make Money in Crypto?
*Can AI Make Money in Crypto?* is a comprehensive benchmark for evaluating AI-based trading methods in cryptocurrency markets. It brings together classical machine learning models, reinforcement learning algorithms, large language models, and autonomous trading agents under a unified evaluation framework. Unlike existing studies that rely mainly on historical backtesting, this project evaluates trading systems across multiple stages, including retrospective backtests, real-time paper trading, and, in the future, live trading with real capital. By comparing performance across these settings, the benchmark aims to examine whether gains reported in historical simulations can persist in unseen and continuously evolving markets, and to provide a transparent, reproducible, and continuously updated platform for AI trading research.
